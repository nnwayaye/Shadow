# Shadow Novel Site\n\nမြန်မာဝတ္ထုများ ဖတ်ရှုရန်နှင့် admin panel ကနေ ဝတ္ထု/အခန်းများ ထည့်ရန် Next.js app ဖြစ်ပါတယ်။\n\n## GitHub Codespaces မှာ run မယ်\n\n1. GitHub repo ထဲက **Code → Codespaces → Create codespace on main** ကိုနှိပ်ပါ။\n2. Codespace ဖွင့်ပြီးရင် .devcontainer က Node 20 environment နဲ့ dependencies ကို အလိုအလျောက်ပြင်ပေးပါလိမ့်မယ်။\n3. Port 3000 ကို auto-forward လုပ်ပြီး Preview ဖွင့်ပါလိမ့်မယ်။ မဖွင့်ရင် **Ports → 3000 → Open in Browser** ကိုနှိပ်ပါ။\n\n## လိုအပ်တဲ့ environment variables\n\nGitHub ရဲ့ **Settings → Codespaces → Secrets** ထဲမှာ အောက်က secrets တွေထည့်ပါ။ တန်ဖိုးအစစ်တွေကို repo ထဲ မတင်ပါနဲ့။\n\n- NEXT_PUBLIC_SUPABASE_URL — Supabase project URL\n- NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY — Supabase publishable key\n- SUPABASE_SERVICE_ROLE_KEY — admin server actions အတွက် server-side key\n- ADMIN_PASSWORD — admin login password\n\nSecret ပြောင်းပြီးရင် Codespace ကို **Rebuild Container** လုပ်ပါ။ Admin login က /admin/login မှာရှိပါတယ်။\n\n## Local run\n\n```bash\ncp .env.example .env.local\nnpm install\nnpm run dev\n```\n\nBrowser မှာ http://localhost:3000 ကိုဖွင့်ပါ။\n\n> SUPABASE_SERVICE_ROLE_KEY ကို browser-side code ထဲ မသုံးပါနဲ့။ Admin operations အတွက် server-side မှာပဲ သုံးထားပါတယ်။\n
